# 文件管家：桌面整理与文件检索

产品现在包含「桌面整理」和「文件检索」两个板块。

## 文件检索

1. 点击「文件检索」。
2. 选择「全电脑 · 本机磁盘」，或点击「选择目标文件夹」选择搜索范围。指定文件夹会包含所有子文件夹。
3. 首次选择范围时点击「增量更新索引」会自动全量建索引；之后新增、删除、改名或移动文件时，使用同一按钮进行增量更新。扫描过程中可以查看进度并停止。停止后的索引会明确标记为部分索引。若要刷新已有文件的修改时间，点击「全量重建」。
4. 输入任意组合的筛选条件，再点击「搜索文件」。
5. 点击结果的「打开文件」或「定位文件夹」。需要清理重复文件时，勾选结果后点击「移入回收站」。

批量操作前会再次确认。程序会先检查文件是否仍与索引时一致；已修改、移走或删除的文件不会被处理。移入 Windows 回收站的文件可从回收站恢复。每次最多选择 100 个文件。

可组合筛选：主题 / 项目名称、关键词、创建或修改日期区间、文件格式。条件之间是“同时满足”。关键词支持中英文，空格、逗号或分号分隔后表示同时包含；文件格式分隔后表示任一格式。

主题可从已登记项目名称中选择，也可直接输入。选中规则名称时，会同时匹配该规则的关键词。例如「水利项目」规则包含「水源」时，位于「水源处」路径下的文件也会命中该主题。

当前搜索对象是文件名和文件夹名/完整路径，不读取文档正文。搜索词匹配到文件夹名时，文件夹会作为独立结果显示，可直接打开或定位；同一路径下的文件也会照常匹配。选择文件格式筛选时只显示文件。时间使用文件系统记录，复制或下载可能改变创建时间。

## 搜索范围与覆盖说明

全电脑范围会扫描 Windows 所有本机固定磁盘；网络盘和移动盘可通过目标文件夹选择加入搜索。系统目录、应用缓存、node_modules、.git、符号链接和无权限项会跳过；扫描统计会展示文件、文件夹及无法访问的项目数量。文件和文件夹各最多索引 50 万项，达到上限后明确标记部分索引，可选择更具体的文件夹继续检索。

索引保存在当前用户应用数据目录。重启后可直接使用已保存的索引。新增、删除、改名或移动文件后需增量更新；若结果已经不存在，打开 / 定位时会提示更新。更换范围后点击「增量更新索引」会为新范围建立索引。

旧版本索引只记录文件，不含独立文件夹目录项。升级后首次搜索文件夹名时，请先点击「建立 / 更新索引」生成新版索引。

默认使用「增量更新索引」：会检查目录变化，对未变化的目录不重新读取内容，并跳过其中已有文件的元数据检查；新建、删除、改名或移动的项目会被同步。若搜索范围改变，或索引没有可用的目录快照，增量更新会自动退回全量扫描。已有文件内容修改不会改变其父目录时间，因此若要刷新这类文件的修改时间筛选，请使用「全量重建」。

「全量重建」会重新检查选定范围的所有文件，可能耗时较长；通常只在修复索引或需要刷新已有文件元数据时使用。索引仍保存在本机，关闭再打开应用不需要重新扫描。

## 桌面整理

沿用桌面第一层文件预览、规则归类、拖拽调整、执行与撤销。搜索覆盖更广范围，整理仍由用户确认预览后执行。

## 文件管理

1. 点击「文件管理」，选择来源文件夹。**操作模式**切换位于「桌面整理 / 文件检索 / 文件管理」标签下方。
2. 默认进入「双栏管理」，两侧初始均为空；分别点击各自的「选择位置」后才会加载文件夹。两侧可分别后退、前进、进入上一级，也可搜索当前位置及其子文件夹中的名称。「单栏管理」保留原有浏览和目标树操作。需要更大空间时，点击模式栏「全屏放大」；点击右侧顶部「缩小」或按 Esc 恢复常规窗口。
3. 两侧都能勾选文件和整个文件夹。将一侧的选择拖到另一侧的空白处，会移入另一侧当前文件夹；拖到另一侧的子文件夹，则移入该子文件夹。也可用左右方向按钮执行移动，所以来源和去向可以互换。
4. 双栏模式支持打开文件、重命名、新建文件夹和删除。重命名及移动可用「撤销移动/重命名」恢复；删除会进入 Windows 回收站，可在那里恢复。跨磁盘移动会先复制并校验，再删除原件；同名项目不会覆盖。
5. 移错或重命名后点击「撤销移动/重命名」可恢复。若原位置已被占用，不会覆盖现有项目；若跨磁盘复制已校验但原件删除失败，会提示副本位置，请检查并手动处理。

文件管理器只读取当前窗格所浏览文件夹的目录项，不读取文档正文。链接不会跟随。跨磁盘移动包含符号链接的文件夹会安全跳过并保留原件；移动、重命名、撤销和移入回收站都会同步更新本机文件检索索引。

## 文件转换

1. 点击「文件转换」，选择一个具体文件夹。左侧持续显示当前文件夹内容，可进入子文件夹、返回上一级或点击路径节点跳转；点击文件名可在右侧预览图片或 PDF 首页。
2. 勾选一个或多个文件后，从「转换为」选择可用格式。支持 PDF 每页导出为 PNG/JPG、PNG/JPG 图片合并为一个 PDF、多个 PDF 合并，以及 DOC/DOCX 与 ODT、XLS/XLSX 与 ODS、PPT/PPTX 与 ODP 的对应转换和 PDF 输出。
3. 转换结果保存在当前文件夹，已有同名结果会自动使用新名称；原文件不会覆盖。完成后可点击「打开转换结果」。PDF 合并按文件勾选顺序处理。
4. 图片/PDF 基础转换在本机离线完成；Office 和 ODF 转换需要安装 LibreOffice。若未安装会提示，不会上传文件。PDF 转 Word/ODT 为尽力转换，复杂排版可能需要整理；扫描 PDF 的 OCR 不在首版范围内。单个 PDF 最多导出 500 页，图片/PDF 批处理最多 50 个文件。
