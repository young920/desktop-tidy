# 桌面清洁助手：文件管理与检索

产品现在包含「桌面整理」和「文件检索」两个板块。

## 文件检索

1. 点击「文件检索」。
2. 选择「全电脑 · 本机磁盘」，或点击「选择目标文件夹」选择搜索范围。指定文件夹会包含所有子文件夹。
3. 点击「建立 / 更新索引」。扫描过程中可以查看进度并停止。停止后的索引会明确标记为部分索引。
4. 输入任意组合的筛选条件，再点击「搜索文件」。
5. 点击结果的「打开文件」或「定位文件夹」。

可组合筛选：主题 / 项目名称、关键词、创建或修改日期区间、文件格式。条件之间是“同时满足”。关键词支持中英文，空格、逗号或分号分隔后表示同时包含；文件格式分隔后表示任一格式。

主题可从已登记项目名称中选择，也可直接输入。选中规则名称时，会同时匹配该规则的关键词。例如「水利项目」规则包含「水源」时，位于「水源处」路径下的文件也会命中该主题。

当前搜索对象是文件名和完整路径，不读取文档正文。时间使用文件系统记录，复制或下载可能改变创建时间。

## 搜索范围与覆盖说明

全电脑范围会扫描 Windows 所有本机固定磁盘；网络盘和移动盘可通过目标文件夹选择加入搜索。系统目录、应用缓存、node_modules、.git、符号链接和无权限项会跳过；扫描统计会展示无法访问的项目数量。每次扫描最多索引 50 万个文件，达到上限后明确标记部分索引，可选择更具体的文件夹继续检索。

索引保存在当前用户应用数据目录。重启后可直接使用已保存的索引。新建、修改或移动文件后需更新索引；若结果已经不存在，打开 / 定位时会提示更新。更换范围后点击「建立 / 更新索引」才生效。

## 桌面整理

沿用桌面第一层文件预览、规则归类、拖拽调整、执行与撤销。搜索覆盖更广范围，整理仍由用户确认预览后执行。
